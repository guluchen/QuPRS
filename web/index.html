About this fork and numerical limits
This browser fork retains QuPRS v0.16.0 verification and classification, pinned to upstream 0b287366. It supports the upstream restricted unitary QASM 2/3 input. The browser preserves rational source phases and runs the upstream MPFR input-weight bridge inside its GPMC v1.0.2 worker at 96–1024 bits, selected by the upstream tolerance policy. Complex counting uses 30 decimal digits. These are numerical working precisions, not certified enclosures.
The displayed metric is minφ ‖U − exp(iφ)V‖F / √(2ⁿ), in the range 0 to √2. It is an average matrix distance, not worst-case input error. Reduction may accept under its tolerance without computing a distance. A printed count outside the unitary range is not assigned a distance.
Each request has a 200-second worker limit. Each WASM module has a 512 MiB linear-memory ceiling. Stop terminates all workers. Timings exclude network download only in the published local-HTTP benchmark, not necessarily on this page.
